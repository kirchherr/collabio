# UX Principles

The suite must support three operation layers:

```text
1. Classic UI
2. Command palette and quick actions
3. Voice and AI assistant
```

## Speed with intent

- Low-risk drafting and summarization should be one click or one command.
- External, destructive, or compliance-relevant actions require visible confirmation.
- Hidden UI actions are never the only protection; server-side permission checks are mandatory.
- AI suggestions explain why they are available and which sources they used.

## MVP targets

- Document summary: one action.
- Mail draft preparation: one action plus send confirmation.
- RAG answer: one question with visible citations.
- Dictation: push-to-talk.
